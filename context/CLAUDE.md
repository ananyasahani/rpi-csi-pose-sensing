# CLAUDE.md lives at the repo root

The canonical standing context for this project is [`../CLAUDE.md`](../CLAUDE.md),
not this file. Everything that was drafted here has been merged into it: the
project definition and scope, the confirmed hardware topology, the locked capture
parameter table, the hard-won technical facts, the repository layout, the coding
conventions, and the current-status log.

It is kept at the repo root because that is where Claude Code auto-loads it at the
start of every session. A second copy in this folder would silently drift out of
sync with the first, which is exactly the failure mode
[`DOCUMENTATION-GUIDE.md`](DOCUMENTATION-GUIDE.md) warns about.

**If you came here to update a fact, edit [`../CLAUDE.md`](../CLAUDE.md) instead.**
See [`README.md`](README.md) for what the rest of this folder contains.
